# daniela_zabala_proyecto_final
TechCovers es una plataforma web desarrollada con Django para consultar un catálogo de accesorios para móviles y gestionar reservas de productos.

Funcionalidades

Consulta del catálogo de productos.

Registro e inicio de sesión de usuarios.

Creación, modificación y eliminación de reservas.

Actualización del stock al gestionar las reservas.

Gestión de productos por parte del administrador.

Tecnologías utilizadas

Python

Django

HTML y CSS

PostgreSQL

Git y GitHub

Vercel

Neon

Ejecución del proyecto

Activar el entorno virtual.

Instalar las dependencias:

pip install -r requirements.txt

Ejecutar el servidor:

python manage.py runserver --insecure

Pruebas

Para ejecutar las pruebas automatizadas:

python manage.py test catalogo --keepdb
